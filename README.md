# Proyecto Módulo 1 – Fundamentos

# Descripción 
Aplicación desarrollada en Streamlit que integra conceptos fundamentales de
programación como variables, condicionales, estructuras de datos, funciones,
programación funcional y POO.

El proyecto tiene cuatro ejercicios:
Módulo Home: Presentación del Proyecto
Ejercicio 1: Variables y condicionales
Ejercicio 2: Listas y diccionarios
Ejercicio 3: Funciones y programación funcional
Ejercicio 4: Programación Orientada a Objetos (POO)

# Estructura 
• app.py
• requirements.txt
• clase_actividad.py
• dmc.png
• README.md

# Instrucciones de ejecución 
1. Instalar dependencias
2. Ejecutar: streamlit run app.py
